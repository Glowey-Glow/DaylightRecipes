# Notes for AI coding assistants

Glowey's Recipes is free software under the GNU General Public License, version 3 or later
(`LICENSE.md`). Its author is Glowey.

- The files in `Data/` are ForeverRecipes' generated tables (by Ismail, GPL-3.0), built from
  ForeverDB.app and CMaNGOS Classic DB. They are kept exactly as ForeverRecipes ships them,
  headers included: don't hand-edit them. Update them by copying a newer ForeverRecipes release's
  `Data/` over them.
- `Data/Polestar.lua` is generated by `Tools/polestar.py` from Polestar's data (GPL-3.0, by the
  Polestar authors; its `Polestar_Codex` folder): sources for the recipes ForeverRecipes has none
  for, reputation requirements, the NPCs those name, and every profession's camping items. Don't
  hand-edit it: run the script again (see its header). Facts Polestar has only from QuestieDB are
  left out there: QuestieDB's facts come in through `Data/Corrections.lua` only. Never use
  CampingKit's or Mastercraft's code or data (All Rights Reserved).
- `Data/Corrections.lua` is generated by `Tools/questie.py` from QuestieDB (the Questie team's;
  used under the GPLv3 terms its LICENSE.md offers, see `LICENSE.md`): it checks every recipe
  item's sources (ForeverRecipes', then Polestar's, as `Where.lua` merges them) against QuestieDB's
  baked Forever store (`QuestieDB_Forever.toc`: CBOR in base64 TOC fields) and writes what to take
  away and add, and the NPC records (names, factions, places) those and our sources need.
  `Where.lua` applies it last: removals, then additions. Don't hand-edit it: run
  `python Tools/questie.py "<AddOns folder>" [--report FILE]` again after a ForeverRecipes, Polestar
  or QuestieDB update (run `Tools/polestar.py` first if Polestar changed). Use only QuestieDB's
  facts, never its code, text or the Questie name and logo.
- The rest is this plugin's own code, built on `DaylightUI.API` only (see DaylightUI's `API.md`).
  DaylightUI and DaylightMogul have their own licenses (All Rights Reserved): read them to
  understand how they work, but never copy their code, art or text into this plugin, and never
  edit them. DaylightMogul is used through `DaylightMogul.API` only, read-only.
- Code from this plugin must not be copied into the author's All Rights Reserved addons
  (Addon Skins, Glowey's Fishing): the GPL would not allow it.
